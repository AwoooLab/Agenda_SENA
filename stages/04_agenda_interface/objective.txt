ETAPA 04 — INTERFAZ DE AGENDA

OBJETIVO
Unir la ventana, el modelo de datos, las validaciones y el guardado JSON para
que el alumno pueda registrar y consultar citas desde la aplicación.

ARCHIVO DE LA ETAPA
Crear o completar:
- stages/04_agenda_interface/app.py

PROMPT PARA CHATGPT GRATUITO
Actúa como profesor de Python. Genera únicamente el contenido del archivo
`app.py` para la etapa 04 de Agenda SENA. Crea una interfaz Tkinter con campos
para título, fecha, hora y descripción, un botón para guardar y una lista que
muestre las citas. Usa funciones separadas para leer los campos, validar y
mostrar mensajes. No inventes librerías externas y no modifiques otros archivos.
Explica al final qué funciones necesita integrar el proyecto principal.

REQUISITOS
- Reutilizar el modelo `Cita`.
- Reutilizar las funciones de validación.
- Reutilizar las funciones de almacenamiento.
- Mostrar errores comprensibles al usuario.
- No colocar toda la lógica en una sola función.

INTEGRACIÓN
La interfaz final debe quedar principalmente en `src/interface.py`.
El archivo raíz `app.py` solo debe iniciar `ejecutar()`.
La interfaz debe comunicarse con `src/model.py`, `src/validation.py` y
`src/storage.py`, sin duplicar sus reglas.

VALIDACIÓN
Ejecutar:
python stages/04_agenda_interface/app.py
python app.py

Resultado esperado: se puede registrar una cita válida, verla en la lista y
recibir un mensaje cuando falte un dato obligatorio.

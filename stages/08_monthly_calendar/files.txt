ETAPA 08 — CALENDARIO MENSUAL
=============================

PROPÓSITO
---------
Construir el calendario mensual antes de conectarlo con las actividades. El
alumno aprenderá fechas, cuadrículas, botones y navegación entre meses.

ARCHIVOS DE LA ETAPA
--------------------
- monthly_calendar.py
- calendar_cell.py
- test_calendar.py
- preview.html

======================================================================
ARCHIVO: calendar_cell.py
======================================================================

PROPÓSITO
---------
Crear una celda reutilizable para mostrar el número de un día.

LIBRERÍAS
---------
- tkinter.
- No consultar SQLite.

LECCIÓN 1 — UNA CELDA ES UN FRAME
---------------------------------
La celda puede ser un Frame con un Button o Label dentro. Debe recibir el día y
una función on_select.

Fragmento:
    boton = tk.Button(parent, text=str(dia), command=lambda: on_select(dia))

LECCIÓN 2 — DÍA ACTUAL Y SELECCIONADO
-------------------------------------
Usar color y texto para que el estado no dependa solo del color. Por ejemplo,
un borde o una etiqueta puede indicar Seleccionado.

LECCIÓN 3 — UBICACIÓN EN LA CUADRÍCULA
--------------------------------------
La celda debe poder ubicarse con grid(row=fila, column=columna).

======================================================================
ARCHIVO: monthly_calendar.py
======================================================================

PROPÓSITO
---------
Crear la vista completa de un mes.

LIBRERÍAS
---------
- tkinter.
- calendar para calcular semanas y días.
- datetime.date y datetime para conocer el mes actual.

LECCIÓN 1 — OBTENER EL MES
--------------------------
Guardar año y mes actuales como números enteros. Si no llegan al constructor,
usar la fecha de hoy.

Fragmento:
    hoy = date.today()
    self.anio = hoy.year
    self.mes = hoy.month

LECCIÓN 2 — NOMBRES EN ESPAÑOL
------------------------------
Crear listas fijas para meses y días:

    meses = ["Enero", "Febrero", "Marzo", ...]
    dias_semana = ["Lun", "Mar", "Mié", "Jue", "Vie", "Sáb", "Dom"]

LECCIÓN 3 — CONSTRUIR LA CUADRÍCULA
-----------------------------------
calendar.Calendar(firstweekday=0).monthdayscalendar(anio, mes) devuelve semanas
con números de día y ceros para las celdas vacías.

LECCIÓN 4 — CAMBIAR DE MES
--------------------------
Si el mes es 1 y se retrocede, pasar a diciembre del año anterior. Si el mes es
12 y se avanza, pasar a enero del año siguiente.

Fragmento:
    if mes == 12:
        mes = 1
        anio += 1

LECCIÓN 5 — BOTONES DE CONTROL
-----------------------------
Crear botones ‹, Hoy y ›. Cada cambio debe actualizar el texto del encabezado y
reconstruir las celdas.

======================================================================
ARCHIVO: test_calendar.py
======================================================================

PROPÓSITO
---------
Comprobar los cálculos sin abrir una ventana.

LIBRERÍAS
---------
- unittest.
- calendar.
- datetime.

CASOS NECESARIOS
----------------
- Febrero de 2028 tiene 29 días.
- Febrero de 2027 tiene 28 días.
- Abril tiene 30 días.
- Enero tiene 31 días.
- Diciembre seguido de enero aumenta el año.
- Enero seguido de diciembre disminuye el año.
- La semana comienza en lunes.

PRUEBA FUNCIONAL OPCIONAL EN EL PC
-------------------
Abrir la demostración del calendario, cambiar de mes, volver a Hoy y seleccionar
un día. Ejecutar también:

    python -m unittest stages/08_monthly_calendar/test_calendar.py -v

INTEGRACIÓN DESPUÉS DE APROBAR EL STAGE
---------------------------------------
Ambos módulos visuales permanecen aislados. Después de validar la etapa, se
conectan en `src/`, se coordinan desde `main.py` y se registran en
`config/integration.json` si su salida visual queda activa.

======================================================================
ARCHIVO: preview.html
======================================================================

PROPÓSITO
---------
Mostrar en el navegador la cuadrícula mensual que después se construirá con
Tkinter.

CONCEPTOS NECESARIOS
--------------------
- Una cuadrícula de siete columnas representa los días de la semana.
- Las celdas vacías conservan la posición del primer día.
- Una clase CSS puede destacar el día actual.
- Una etiqueta interna puede mostrar una actividad.

FRAGMENTO DE REFERENCIA
-----------------------
    <div class="dias">
      <div class="dia vacio"></div>
      <div class="dia hoy"><strong>23</strong></div>
    </div>

VALIDACIÓN VISUAL EN GITHUB PAGES
------------
Subir los archivos de esta etapa y abrir únicamente la página
principal https://awooolab.github.io/Agenda_SENA/. Comprobar allí que el mes

fechas.

CONTRATO DE INDEPENDENCIA E INTEGRACIÓN
----------------------------------------
Este stage se construye como un módulo independiente. No debe importar archivos
de otros stages ni depender de que otra etapa esté terminada. Sus datos de
prueba, entradas, salidas y validaciones pertenecen únicamente a este módulo.

preview.html representa este stage y se revisa desde la única página principal:
https://awooolab.github.io/Agenda_SENA/
La página principal no carga automáticamente todos los previews existentes.
Solo muestra los módulos aprobados que estén registrados en
config/integration.json.

Después de aprobar el stage, la integración se realiza fuera de esta carpeta,
en src/, main.py y config/integration.json. El estudiante no modifica esos
archivos durante la lección. La acumulación ocurre únicamente en la aplicación
integrada.

Antes de integrar, comprobar la entrada independiente, la salida producida,
las funciones públicas, los datos de prueba, las validaciones, los errores y
el punto de conexión futuro. Este módulo no debe conservar funciones de otros
stages dentro de su propio código.

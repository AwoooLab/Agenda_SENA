ETAPA 03 — GUARDADO JSON

OBJETIVO
Guardar y recuperar las citas en un archivo JSON local, sin depender de
Internet ni de una base de datos externa.

ARCHIVOS DE LA ETAPA
Crear o completar:
- etapas/03_guardado_json/almacenamiento.py
- etapas/03_guardado_json/demo.py
- datos/agenda.json

PROMPT PARA CHATGPT GRATUITO — almacenamiento.py
Actúa como profesor de Python. Genera únicamente el archivo `almacenamiento.py`
para Agenda SENA. Crea una función `guardar(datos, ruta)` que escriba una lista
de diccionarios en JSON con indentación y codificación UTF-8, y una función
`cargar(ruta)` que lea esa lista. Usa únicamente `json` y `pathlib`.
No generes interfaz gráfica ni otros archivos.

REQUISITOS
- Usar JSON válido.
- Usar UTF-8.
- Crear la carpeta padre si no existe.
- Mantener separada la lectura y escritura de la interfaz.
- Controlar de forma clara si el archivo todavía no existe.

INTEGRACIÓN
La versión final debe quedar en `src/almacenamiento.py` y trabajar con
`src.modelo.Cita`. El archivo `datos/agenda.json` será el almacenamiento inicial.
La interfaz usará `cargar_agenda()` al iniciar y `guardar_agenda()` al registrar cambios.

VALIDACIÓN
Ejecutar:
python etapas/03_guardado_json/demo.py
python -m unittest discover -s pruebas -v

Resultado esperado: se guarda una cita, se lee nuevamente y los datos coinciden.

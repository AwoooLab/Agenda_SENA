ETAPA 01 — VENTANA PYTHON

OBJETIVO
Crear la primera ventana de escritorio de Agenda SENA usando Python y Tkinter.

ARCHIVO DE LA ETAPA
Crear o completar:
- etapas/01_ventana_python/app.py

PROMPT PARA CHATGPT GRATUITO
Actúa como profesor de Python. Estamos construyendo Agenda SENA por etapas.
Genera únicamente el contenido del archivo `app.py` para la etapa 01.
Debe abrir una ventana Tkinter titulada "Agenda SENA", mostrar el nombre del
proyecto y tener un botón para cerrar. Usa únicamente la biblioteca estándar.
No generes otros archivos, no agregues bases de datos y explica brevemente cómo
ejecutarlo al final.

REQUISITOS
- Python 3.
- Tkinter.
- Ventana con título visible.
- Botón Cerrar.
- Código pequeño y fácil de leer.

INTEGRACIÓN
Después de validar el archivo, llevar el comportamiento de la ventana a:
- app.py, como punto de entrada.
- src/interfaz.py, como módulo de la interfaz.
El archivo raíz `app.py` debe iniciar la función `ejecutar()` de `src/interfaz.py`.

VALIDACIÓN
Ejecutar desde la raíz del proyecto:
python etapas/01_ventana_python/app.py
python app.py

Resultado esperado: aparece una ventana con el nombre Agenda SENA y se puede cerrar.

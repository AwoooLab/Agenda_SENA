# Parte NN — Nombre de la parte

## Propósito

Explicar qué capacidad nueva se construirá en esta parte y por qué pertenece a
un bloque separado del proyecto.

## Requisitos previos

- Indicar qué parte debe estar terminada.
- Indicar qué funcionalidades o conceptos se reutilizan.

## Resultado final

Describir qué podrá hacer la aplicación cuando se completen todos los hitos de
esta parte.

## Hitos

Crear una carpeta `milestones/` y agregar una especificación por hito. Cada
especificación debe incluir:

- propósito;
- archivos que se crearán o actualizarán;
- requisitos funcionales y visuales;
- restricciones;
- instrucciones para solicitar ayuda a ChatGPT por archivo;
- validación visual en la página principal de GitHub Pages;
- integración posterior en `main.py`;
- criterio de terminado.

## Stages relacionados

Anotar aquí las carpetas de `stages/` que se utilizarán. Cada stage debe
permanecer aislado durante la lección y contener su propio `files.txt` y
`preview.html` cuando corresponda.

## Integración de la parte

Explicar qué se incorpora en `src/` y `main.py`, y qué módulos aprobados se
registran en `config/integration.json` al terminar la parte. `index.html` es el
único visor de la aplicación integrada; no carga automáticamente todos los
previews.

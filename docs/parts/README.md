# Partes del proyecto

Agenda SENA se construirá por partes. Cada parte representa un bloque de
aprendizaje con un objetivo propio, sus hitos y sus archivos de trabajo.

## Partes disponibles

| Parte | Tema | Estado | Documentación |
|---|---|---|---|
| 01 | Agenda local para PC | Preparada | [Abrir Parte 1](01_agenda_pc/README.md) |

## Cómo agregar una parte futura

1. Copiar la estructura de `_part_template/`.
2. Asignarle un número y un nombre en inglés, por ejemplo
   `02_sync_and_reports/`.
3. Definir en su `README.md` el objetivo, los requisitos previos y el resultado
   final.
4. Crear dentro una carpeta `milestones/` con los hitos de esa parte.
5. Relacionar cada hito con los archivos de trabajo que correspondan en
   `stages/`.
6. Actualizar esta tabla y el índice de documentación.

Una parte nueva no debe modificar el significado de los hitos anteriores. Si
necesita cambiar una decisión de la Parte 1, se documenta como un nuevo hito o
como una migración explícita.
